# E-Commerce Store

A Django e-commerce web app with product browsing, user authentication, cart, orders, wishlist, and reviews.

## Features

- Product listing and product detail pages
- Register, login, and logout
- Shopping cart flow
- Wishlist management
- Order placement and order history
- Product reviews
- Django admin dashboard

## Tech Stack

- Python
- Django
- SQLite for local/demo data
- Gunicorn for production serving
- WhiteNoise for static files on Render

## Run Locally

```powershell
.\venv\Scripts\python.exe manage.py migrate
.\venv\Scripts\python.exe manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```

## Render Deployment

This project is configured in the root `render.yaml` as:

```text
Service: codealpha-ecommerce-store
Root Directory: E_Commerce_Store
Build Command: bash build.sh
Start Command: gunicorn backend.wsgi:application
```

Environment variables used on Render:

```text
DJANGO_SECRET_KEY=generated by Render
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=.onrender.com,localhost,127.0.0.1
DJANGO_CSRF_TRUSTED_ORIGINS=https://*.onrender.com
```

## Notes

The app currently uses SQLite, which is fine for a demo deployment. For a production store, move the database to PostgreSQL and configure persistent media storage.
